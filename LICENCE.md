## 🧩 About

**Knight Online Grind** is a companion overlay for Knight Online featuring EXP and drop tracking, loot radar, mob spawn overlay, auto-pot support, farm route assistant, and grind session statistics.

Inspired by community tools like **KO Helper**, **Knight Tracker**, and classic MMO overlay utilities.

---

## ✨ Features

### 🎮 Grind Assist
- EXP Tracker — live EXP/hour and time-to-level estimates
- Loot Radar — highlight drops and rare item spawns
- Mob Tracker — overlay markers for nearby monsters
- Farm Route Helper — suggested grind loops per zone

### 🗺️ Overlay & HUD
- Map Overlay — zone map with markers and waypoints
- HUD Panel — session kills, drops, and EXP summary
- Auto-Pot — timed HP/MP potion triggers
- Party Overlay — track nearby party members

### 🏋️ Session Tools
- Drop Log — record notable loot per session
- Grind Timer — track play and break intervals
- Config Profiles — save settings per character
- Safe Mode — restrict risky features
